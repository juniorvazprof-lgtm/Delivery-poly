# Contrato de uma cena (módulo ES) — vídeo vertical "tech thriller" 3D em Three.js

Arquivo: `cenas/<nome>.js`. Exporta UMA função default:

```js
export default function criar(ctx) {
  const g = new ctx.THREE.Group();   // TUDO da cena vai dentro de g (o motor adiciona g à cena e liga/desliga a visibilidade)
  // ... montar objetos uma única vez aqui ...
  return {
    grupo: g,
    update(t, k, dur) { /* chamado a cada quadro enquanto a cena está ativa */ }
  };
}
```

- `t` = tempo absoluto do vídeo em segundos; `k` = tempo desde o início da cena (0..dur); `dur` = duração da cena.
- O motor renderiza quadro a quadro de forma DETERMINÍSTICA (pode pular ou voltar no tempo). Portanto:
  - **Proibido** `Math.random`, `Date`, `performance.now`, `requestAnimationFrame`, setTimeout, GSAP, estado que acumula entre quadros. Todo movimento é função pura de `t`/`k`.
  - Para aleatoriedade fixa use `const rnd = ctx.rnd(semente)` NA CRIAÇÃO (retorna função que dá 0..1).
- Nada de imports. Use só o que vem no `ctx`.

## O que vem no ctx
- `ctx.THREE` (three r170), `ctx.RoundedBoxGeometry` (classe: `new ctx.RoundedBoxGeometry(w,h,d,segs,raio)`).
- `ctx.cam`: PerspectiveCamera fov 40, aspecto 9:16. **Toda cena DEVE posicionar a câmera em todo update** (`ctx.cam.position.set(...)`, `ctx.cam.lookAt(...)`); zere `ctx.cam.rotation.z` não é preciso (lookAt resolve).
- `ctx.fx`: objeto de efeitos que o motor zera a cada quadro; a cena pode escrever:
  - `ctx.fx.shake` 0..1.5 (tremida de câmera), `ctx.fx.gl` 0..1 (glitch de faixas), `ctx.fx.red` 0..0.8 (tingir de vermelho),
    `ctx.fx.ab` (aberração cromática, padrão 0.002, impacto ~0.02), `ctx.fx.flash` 0..1 (clarão branco), `ctx.fx.bloom` (padrão 1.1; use ~0.5 se houver telas/superfícies muito claras).
- `ctx.ease(x)` easeOutCubic com clamp 0..1; `ctx.pulso(t, freq)` 0..1 senoidal; `ctx.clamp01(x)`.
- `ctx.cores`: `{ verm:'#ff2b3d', azul:'#2fa8ff', amarelo:'#ffe14a', verde:'#25d366', fundo:'#03060d', branco:'#f2f4f8' }`.
- `ctx.telaCanvas(w, h)` → `{ canvas, g2d, tex }`: canvas 2D já ligado a uma CanvasTexture sRGB. Depois de desenhar em `g2d`, faça `tex.needsUpdate = true`. Fontes disponíveis no canvas: `'Archivo'` (bold grossa) e `'Anton'` (condensada). Ex.: `g2d.font = '64px Archivo'`.
- `ctx.textoPlano(texto, {tamanho=64, cor='#fff', fonte='Archivo', largura=2})` → Mesh (plano) com o texto desenhado, largura em unidades do mundo = `largura`. Bom para placas e letreiros.
- Luzes: o motor já tem AmbientLight 0.6 e uma DirectionalLight azulada. Pode adicionar luzes DENTRO de g (PointLight com intensidade ≤ 8).
- Névoa exponencial escura (densidade 0.035) e fundo `#03060d`: objetos a mais de ~25 unidades somem.

## Regras de composição (vertical 1080x1920)
- O terço inferior-meio da tela (de ~58% a ~72% da altura) é ocupado por LEGENDAS GRANDES desenhadas pelo motor. **O assunto principal deve ficar na metade de cima da tela** (enquadre com a câmera: ex. objeto em y=+1.5 e lookAt em y=0, ou câmera levemente baixa).
- Estilo: escuro, neon, vermelho de alerta (#ff2b3d) contra azul (#2fa8ff), materiais `MeshStandardMaterial` metálicos escuros ou `MeshBasicMaterial` emissivos para neon (o bloom faz brilhar). Low-poly limpo, nada de texturas externas.
- Movimento constante: câmera sempre se movendo (dolly/órbita lenta) e PELO MENOS um evento visual forte sincronizado com cada palavra-chave listada (tempos absolutos `t`). Entradas de objetos com "pop" (escala 0→1.15→1 em ~0.2s), impactos com `ctx.fx.shake`/`flash`.
- Cada evento deve ser legível em celular: poucos objetos grandes, alto contraste.
- Tamanho de referência: com a câmera a ~12 unidades, a largura visível é ~4.8 unidades.

export default function criar(ctx) {
  const T = ctx.THREE;
  const g = new T.Group();
  const C = ctx.cores;

  // ---------- CÂMERA BASE ----------
  // frontal, dolly in lento, zoom out no fim

  // ---------- PLACA "PARTE 2" ----------
  const placaGroup = new T.Group();
  placaGroup.position.set(0, 1.55, 0);
  g.add(placaGroup);

  // moldura holográfica
  const molduraGeo = new ctx.RoundedBoxGeometry(3.4, 1.15, 0.08, 3, 0.06);
  const molduraMat = new T.MeshStandardMaterial({
    color: 0x0a1830, metalness: 0.9, roughness: 0.35,
    emissive: new T.Color(C.azul), emissiveIntensity: 0.25
  });
  const moldura = new T.Mesh(molduraGeo, molduraMat);
  placaGroup.add(moldura);

  // borda neon
  const bordaGeo = new T.EdgesGeometry(new T.BoxGeometry(3.4, 1.15, 0.08));
  const bordaMat = new T.LineBasicMaterial({ color: C.azul });
  const borda = new T.LineSegments(bordaGeo, bordaMat);
  placaGroup.add(borda);

  // texto PARTE 2
  const textoPlaca = ctx.textoPlano('PARTE 2', {
    tamanho: 128, cor: C.azul, fonte: 'Anton', largura: 2.9
  });
  textoPlaca.position.set(0, 0, 0.06);
  placaGroup.add(textoPlaca);

  // faixas de varredura (planos horizontais que revelam)
  const faixas = [];
  const nFaixas = 14;
  for (let i = 0; i < nFaixas; i++) {
    const fGeo = new T.PlaneGeometry(3.4, 1.15 / nFaixas);
    const fMat = new T.MeshBasicMaterial({
      color: C.azul, transparent: true, opacity: 0.0,
      blending: T.AdditiveBlending, depthWrite: false
    });
    const f = new T.Mesh(fGeo, fMat);
    f.position.set(0, 0.575 - (i + 0.5) * (1.15 / nFaixas), 0.07);
    placaGroup.add(f);
    faixas.push(f);
  }

  // ---------- RELÓGIO 24:00:00 ----------
  const relogioGroup = new T.Group();
  relogioGroup.position.set(0, -0.05, 0);
  g.add(relogioGroup);

  const telaRel = ctx.telaCanvas(512, 256);
  const relTex = telaRel.tex;
  const relMat = new T.MeshBasicMaterial({ map: relTex, transparent: true });
  const relMesh = new T.Mesh(new T.PlaneGeometry(2.6, 1.3), relMat);
  relogioGroup.add(relMesh);

  // anel de progresso
  const anelGeo = new T.RingGeometry(1.55, 1.72, 64, 1, 0, Math.PI * 2);
  const anelMat = new T.MeshBasicMaterial({
    color: C.vermel, transparent: true, opacity: 0.9,
    side: T.DoubleSide, blending: T.AdditiveBlending, depthWrite: false
  });
  const anel = new T.Mesh(anelGeo, anelMat);
  anel.position.z = -0.02;
  relogioGroup.add(anel);

  // fundo escuro do relógio
  const relFundo = new T.Mesh(
    new T.PlaneGeometry(2.9, 1.5),
    new T.MeshBasicMaterial({ color: 0x050a14, transparent: true, opacity: 0.85 })
  );
  relFundo.position.z = -0.05;
  relogioGroup.add(relFundo);

  // ---------- BOTÃO SEGUIR ----------
  const botaoGroup = new T.Group();
  botaoGroup.position.set(0, -1.55, 0);
  g.add(botaoGroup);

  const btnGeo = new ctx.RoundedBoxGeometry(2.4, 0.75, 0.35, 4, 0.14);
  const btnMat = new T.MeshStandardMaterial({
    color: 0x8a0f1a, metalness: 0.6, roughness: 0.3,
    emissive: new T.Color(C.vermel), emissiveIntensity: 0.6
  });
  const botao = new T.Mesh(btnGeo, btnMat);
  botaoGroup.add(botao);

  const btnTexto = ctx.textoPlano('SEGUIR', {
    tamanho: 96, cor: '#ffffff', fonte: 'Archivo', largura: 1.6
  });
  btnTexto.position.set(0, 0, 0.2);
  botaoGroup.add(btnTexto);

  // brilho do botão
  const btnGlow = new T.Mesh(
    new T.PlaneGeometry(3.0, 1.1),
    new T.MeshBasicMaterial({
      color: C.vermel, transparent: true, opacity: 0.0,
      blending: T.AdditiveBlending, depthWrite: false
    })
  );
  btnGlow.position.z = -0.2;
  botaoGroup.add(btnGlow);

  // cursor (cone)
  const cursor = new T.Mesh(
    new T.ConeGeometry(0.12, 0.4, 8),
    new T.MeshStandardMaterial({
      color: 0xffffff, metalness: 0.8, roughness: 0.2,
      emissive: new T.Color(C.branco), emissiveIntensity: 0.4
    })
  );
  cursor.rotation.x = Math.PI / 2;
  cursor.position.set(0.9, -1.0, 1.2);
  g.add(cursor);

  // partículas (esferas)
  const particulas = [];
  const rnd = ctx.rnd(1337);
  for (let i = 0; i < 24; i++) {
    const p = new T.Mesh(
      new T.SphereGeometry(0.04 + rnd() * 0.04, 6, 6),
      new T.MeshBasicMaterial({
        color: i % 2 === 0 ? C.vermel : C.amarelo,
        transparent: true, opacity: 0.0,
        blending: T.AdditiveBlending, depthWrite: false
      })
    );
    p.userData = {
      dir: new T.Vector3((rnd() - 0.5) * 2, (rnd() - 0.5) * 2, (rnd() - 0.5) * 2).normalize(),
      vel: 0.8 + rnd() * 1.2
    };
    p.position.copy(botaoGroup.position);
    g.add(p);
    particulas.push(p);
  }

  // luz vermelha do botão
  const luzBtn = new T.PointLight(C.vermel, 0, 8);
  luzBtn.position.set(0, -1.5, 1.5);
  g.add(luzBtn);

  // ---------- ESTADO INICIAL ----------
  placaGroup.scale.set(0.001, 0.001, 0.001);
  relogioGroup.scale.set(0.001, 0.001, 0.001);
  botaoGroup.scale.set(0.001, 0.001, 0.001);

  // ---------- UPDATE ----------
  return {
    grupo: g,
    update(t, k, dur) {
      // reset fx
      ctx.fx.shake = 0;
      ctx.fx.gl = 0;
      ctx.fx.red = 0;
      ctx.fx.ab = 0.002;
      ctx.fx.flash = 0;
      ctx.fx.bloom = 1.1;

      // ---------- CÂMERA ----------
      const prog = ctx.clamp01(k / dur);
      // dolly in lento até ~70%, depois zoom out
      let camZ;
      if (prog < 0.7) {
        camZ = 12.5 - prog * 1.8;
      } else {
        camZ = 11.24 + (prog - 0.7) * 3.5;
      }
      const camY = 0.3 + Math.sin(k * 0.6) * 0.05;
      ctx.cam.position.set(Math.sin(k * 0.3) * 0.15, camY, camZ);
      ctx.cam.lookAt(0, 0.15, 0);

      // ---------- PLACA PARTE 2 ----------
      const tPlaca = 45.74;
      const kPlaca = t - tPlaca;
      if (kPlaca >= 0) {
        // pop de entrada
        const pop = ctx.ease(ctx.clamp01(kPlaca / 0.25));
        const sc = pop < 1 ? pop * 1.15 : 1;
        placaGroup.scale.setScalar(sc);

        // faixas de varredura: revelam de cima para baixo
        const revealProg = ctx.clamp01(kPlaca / 0.5);
        for (let i = 0; i < nFaixas; i++) {
          const limiar = i / nFaixas;
          const local = ctx.clamp01((revealProg - limiar) * 4);
          faixas[i].material.opacity = local * 0.6 * (1 - ctx.clamp01((revealProg - limiar - 0.15) * 4));
        }
        // borda pulsa
        bordaMat.color.setStyle(C.azul);
        molduraMat.emissiveIntensity = 0.25 + ctx.pulso(t, 2) * 0.15;
      } else {
        placaGroup.scale.setScalar(0.001);
      }

      // ---------- RELÓGIO ----------
      const tRel = 46.96;
      const kRel = t - tRel;
      if (kRel >= 0) {
        const pop = ctx.ease(ctx.clamp01(kRel / 0.25));
        relogioGroup.scale.setScalar(pop < 1 ? pop * 1.1 : 1);

        // contagem regressiva: de 24:00:00 para baixo rápido
        const tImpacto = 47.56;
        const kCont = ctx.clamp01((t - tRel) / (tImpacto - tRel));
        const totalSeg = 24 * 3600;
        const restante = Math.max(0, totalSeg * (1 - kCont * 0.999));
        const hh = Math.floor(restante / 3600);
        const mm = Math.floor((restante % 3600) / 60);
        const ss = Math.floor(restante % 60);
        const pad = (n) => String(n).padStart(2, '0');

        const g2d = telaRel.g2d;
        g2d.clearRect(0, 0, 512, 256);
        // fundo
        g2d.fillStyle = 'rgba(5,10,20,0.9)';
        g2d.fillRect(0, 0, 512, 256);
        // texto neon
        g2d.font = 'bold 96px Archivo';
        g2d.textAlign = 'center';
        g2d.textBaseline = 'middle';
        g2d.shadowColor = C.vermel;
        g2d.shadowBlur = 24;
        g2d.fillStyle = C.vermel;
        g2d.fillText(pad(hh) + ':' + pad(mm) + ':' + pad(ss), 256, 128);
        g2d.shadowBlur = 0;
        relTex.needsUpdate = true;

        // anel de progresso
        const theta = Math.PI * 2 * kCont;
        anel.geometry.dispose();
        anel.geometry = new T.RingGeometry(1.55, 1.72, 64, 1, Math.PI / 2, -theta);
        anelMat.opacity = 0.9;

        // impacto em 47.56
        const kImp = t - tImpacto;
        if (kImp >= 0 && kImp < 0.4) {
          const f = 1 - kImp / 0.4;
          ctx.fx.shake = Math.max(ctx.fx.shake, 0.6 * f);
          ctx.fx.flash = Math.max(ctx.fx.flash, 0.35 * f);
          ctx.fx.ab = 0.002 + 0.02 * f;
          relogioGroup.scale.setScalar(1 + 0.15 * f);
          anelMat.color.setStyle(C.amarelo);
        } else {
          anelMat.color.setStyle(C.vermel);
        }
      } else {
        relogioGroup.scale.setScalar(0.001);
      }

      // ---------- BOTÃO SEGUIR ----------
      const tBtn = 48.90;
      const kBtn = t - tBtn;
      if (kBtn >= 0) {
        const pop = ctx.ease(ctx.clamp01(kBtn / 0.25));
        let sc = pop < 1 ? pop * 1.15 : 1;
        // pulso
        const pulso = 1 + ctx.pulso(t, 3) * 0.04;
        botaoGroup.scale.setScalar(sc * pulso);

        // brilho
        btnGlow.material.opacity = 0.15 + ctx.pulso(t, 3) * 0.15;
        luzBtn.intensity = 2 + ctx.pulso(t, 3) * 2;

        // cursor se aproxima
        const kCursor = ctx.clamp01((t - 48.9) / 0.5);
        cursor.position.set(
          0.9 - kCursor * 0.9,
          -1.0 + kCursor * 0.5,
          1.2 - kCursor * 0.9
        );
        cursor.rotation.z = kCursor * 0.3;

        // aperto em 49.42
        const tPress = 49.42;
        const kPress = t - tPress;
        if (kPress >= 0 && kPress < 0.5) {
          const f = 1 - kPress / 0.5;
          // afunda em z e volta
          const afunda = Math.sin(ctx.clamp01(kPress / 0.15) * Math.PI) * 0.25;
          botao.position.z = -afunda;
          btnTexto.position.z = 0.2 - afunda;
          btnMat.emissiveIntensity = 0.6 + f * 1.5;

          if (kPress < 0.15) {
            ctx.fx.flash = Math.max(ctx.fx.flash, 0.5 * (1 - kPress / 0.15));
            ctx.fx.shake = Math.max(ctx.fx.shake, 0.4 * (1 - kPress / 0.15));
          }

          // partículas
          for (let i = 0; i < particulas.length; i++) {
            const p = particulas[i];
            const d = p.userData.dir;
            const v = p.userData.vel;
            const tt = kPress;
            p.position.set(
              botaoGroup.position.x + d.x * v * tt * 2,
              botaoGroup.position.y + d.y * v * tt * 2,
              botaoGroup.position.z + d.z * v * tt * 2 + 0.3
            );
            p.material.opacity = Math.max(0, 1 - tt / 0.5);
            p.scale.setScalar(1 - tt / 0.5);
          }
        } else {
          botao.position.z = 0;
          btnTexto.position.z = 0.2;
          btnMat.emissiveIntensity = 0.6;
          for (let i = 0; i < particulas.length; i++) {
            particulas[i].material.opacity = 0;
          }
        }
      } else {
        botaoGroup.scale.setScalar(0.001);
        for (let i = 0; i < particulas.length; i++) {
          particulas[i].material.opacity = 0;
        }
      }

      // ---------- FX GLOBAIS ----------
      // leve aberração cromática constante
      ctx.fx.ab = Math.max(ctx.fx.ab, 0.003);
      // vermelho de alerta sutil no fim
      if (t > 49.42) {
        ctx.fx.red = Math.max(ctx.fx.red, 0.15 * (1 - ctx.clamp01((t - 49.42) / 0.6)));
      }
    }
  };
}
